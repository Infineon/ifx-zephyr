# Infineon Downstream Zephyr

Infineon downstream fork of the
[Zephyr RTOS](https://github.com/zephyrproject-rtos/zephyr). Based on upstream
Zephyr **v4.4.1**.

Upstream Zephyr README: [`README.zephyr.rst`](README.zephyr.rst) ·
docs: <https://docs.zephyrproject.org>

## Commit tags

- `[zep fromtree]` — merged upstream, back-ported here
- `[zep fromlist]` — submitted upstream, in review
- `[zep noup]` — downstream-only
- `dirty` — adapted during back-port

Tagging convention follows the
[mbedTLS additional-patches](https://github.com/zephyrproject-rtos/mbedtls#additional-patches)
model.

List downstream additions:

```sh
git log --oneline v4.4.1..HEAD
```
